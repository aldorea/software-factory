# Software factory

A personal factory that takes a GitHub issue of a TypeScript repo and returns a verified pull request for human review.

The documentation and the rules for agents live in `docs/`. Read the document that covers your task before you change anything.

## Index

- [`docs/design.md`](docs/design.md): goal, commands, flow, verification, exit and stop conditions, architecture (coordinator, worker layer, agents and authentication, parallelism, git) and measurement.
